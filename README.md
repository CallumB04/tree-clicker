# tree-clicker

A 2D idle clicker game about growing trees.

This is the first game I've built using the Godot engine, where I experimented with different features to learn the basics of the engine.

## Installation and Setup

### Prerequisites

- [Godot Engine](https://godotengine.org/download) installed on your machine.

### Setup

- Clone the repository
- Open the project in Godot, and run the game from the editor
